<h1 align="center">Kint for Craft CMS</h1>

Kint is a Craft CMS plugin that brings an interactive PHP debugger to Craft development. Inspect variables from Twig or PHP with readable structure, useful type information, and less guesswork than a raw dump.

Craft objects get complicated quickly, and a wall of raw output rarely makes them clearer. Send a variable to Kint and explore its arrays, properties and types through collapsible, structured output.

## Features

- Inspect variables at the point where a Craft template uses them.
- Use Kint from modules, plugins, and project code.
- Explore properties, types and nested values in collapsible, navigable output.
- Tune how much of large values should be expanded.
- Keep debugging available for development and disabled where it should not render.
